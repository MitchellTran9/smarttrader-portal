## ⚙️ Cloudflare Pages Deployment (1-Minute Setup)

1. Log into your [Cloudflare Dashboard](https://dash.cloudflare.com/) $\rightarrow$ **Workers & Pages** $\rightarrow$ **Create application** $\rightarrow$ **Pages** $\rightarrow$ **Connect to Git**.
2. Select GitHub repository: **`MitchellTran9/smarttrader-portal`**.
3. Configure Build Settings:
   - **Framework preset:** `Astro`
   - **Build command:** `npm run build`
   - **Build output directory:** `dist`
4. Add Environment Variables:
   - `NOTION_TOKEN`: Your Notion Integration Token (`ntn_...`)
   - `NOTION_DATABASE_ID`: `41cf9e89-fc4f-80d2-9ef9-d7138a59c09b`
5. Click **Save and Deploy**.
6. Under **Custom Domains**, attach **`smarttrader.vip`** (and optional `www.smarttrader.vip`).
